# SPCRJointDynamics for Unreal Engine 5.8

This directory contains the Unreal Engine 5.8 source version of the plugin.

## Install

Copy `Plugins/SPCRJointDynamics` into your Unreal project, then regenerate project
files or enable the plugin in the Unreal Editor.

This directory includes precompiled Win64 editor binaries built with Unreal
Engine 5.8.0.
